# ADR-001 — Versions de la stack
NestJS **11** (CommonJS) plutôt que 12 (ESM-only, API récente non éprouvée ici) ; Prisma **6.19** (`prisma-client-js`) plutôt que 7 (nouveau générateur + adaptateurs obligatoires) ; TypeScript 5.9. Conforme à B01 (NestJS/TS/PostgreSQL/Prisma). Montée de version à planifier après scan de sécurité.
